# Assignment 4 - Forms and Validation

Arnur Kozhabergen, SE-2529

A small website for Web Technologies 1 with HTML forms, Bootstrap 5 styling and validation.

Live website: https://arnur-kozhabergen.github.io/web.asmnt4/

## Pages

- `index.html` - Task 0: contact form with name, email, message and labels
- `html-validation.html` - Task 1: required fields, email format and length limits
- `bootstrap-form.html` - Task 2: contact form using Bootstrap Grid and form classes
- `bootstrap-validation.html` - Task 3: valid and invalid feedback below the fields
- `registration.html` - Task 4: registration with matching passwords, radio buttons, checkboxes, country selection and Reset

## Open the website

Use the live link or open `index.html` in a browser. The navigation bar links to all five tasks. Bootstrap is loaded from a CDN, so an internet connection is needed for its styles. There is no installation or build step.

## Try the validation

1. On Task 1, submit an empty form. Then try an invalid email and a message shorter than 10 characters. The browser blocks invalid submissions.
2. On Task 3, submit the form to see feedback. Correct the fields to see the messages change.
3. On Task 4, try a password shorter than 8 characters and two different passwords. Select a gender and country. Hobbies are optional.
4. Change the first password after confirming it to check that matching is checked again.
5. Click Reset to clear the registration fields and feedback.
6. Narrow the browser window to see the columns stack.

All forms are demonstrations. They show a confirmation on the page without sending messages, saving passwords or creating an account.
